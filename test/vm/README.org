#+TITLE: GNU Guix VM for testing.
#+AUTHOR: tusharhero

See =(info "(guix) Invoking guix system")=.

The basic command is:
#+begin_src bash
  sudo -sE $(guix system vm x.scm --share=$PWD/../../=/emureader) -m 2048
#+end_src

+ =-m= describes the amount of memory available to the vm.
+ =--share= shares the emureader project with the vm at
  /emureader.

Adjust the command accordingly.
