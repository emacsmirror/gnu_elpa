# Contributing to emacs-perl-doc

If you found a bug, or have an idea for improving emacs-perl-doc,
please don't hold back!

Feedback is welcome, preferably using the usual GitHub features like
issues and pull requests.  For a bug report, please describe the
symptom in the subject and include a recipe to reproduce the bug.  You
can also file an issue if you have an idea for improvement.

For pull requests, please keep in mind that emacs-perl-doc is being
published via [GNU ELPA](https://elpa.gnu.org/) and is bound to its
copyright rules.  Quoting from the CONTRIBUTE file from Emacs itself:

  * Once the cumulative amount of your submissions exceeds a dozen or so
	lines of non-trivial changes, we will need you to assign to the FSF
	the copyright for your contributions.

The Free Software Foundation explains [Why the FSF Gets Copyright
Assignments from
Contributors](https://www.gnu.org/licenses/why-assign.html).  If you
want to start that process, fill the
[form](https://cgit.git.savannah.gnu.org/cgit/gnulib.git/plain/doc/Copyright/request-assign.future)
and send it to assign@gnu.org.

The prefered format for pull requests is what `git format-patch`
provides.  The first line of the commit message should be a short
summary of what the patch does.

Thank you!
